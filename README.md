# Premium Digital Agency Website

A high-end digital studio website concept created as a portfolio project by Alper Sancar.

## Purpose
This project demonstrates a different skill set from application dashboards: premium web design, art direction, responsive layout, typography, motion and interaction design.

## Highlights
- Editorial hero composition
- Premium dark visual direction
- Custom project showcase layouts
- Responsive mobile experience
- Scroll reveal animations with Intersection Observer
- Animated marquee
- Pointer-reactive visual elements
- Services and studio storytelling sections
- Strong CTA/contact experience
- Accessible semantic structure

## Stack
HTML5, CSS3, Vanilla JavaScript, Intersection Observer API, responsive CSS.

## Design Note
NOVA is a fictional studio identity created solely for this portfolio concept. Project names and case-study visuals are fictional design exercises and are not presented as client work.

Built by Alper Sancar to demonstrate UI/UX, front-end development, responsive design, creative direction and interactive web experiences.
